My dotfiles configurations. This includes my nvim config, my i3 using polybar and rofi, zshrc and others. 

This repo was made using Stow to manage all the configuration files correctly.

In order to run everything, just clone the repo, cd into it and run `stow .` to symlink all the files inside the repo to the `~/.config` directory. Or manually stow each of the folders e.g `stow nvim/`.
